# PARTE 1 — DISEÑO DE PÁGINA

## 1. Antes de diseñar

Jerarquía: trama → personaje → escena → página → viñeta. La página determina qué mostramos; la viñeta, dónde mira el lector. No invertir este orden solo porque una imagen podría verse espectacular.

No arrancar con "necesito N viñetas". Preguntar primero cuántos instantes merecen verse. La cantidad surge del ritmo y la cantidad de cambios significativos.

## 2. Cantidad de viñetas — guía rápida

| Cantidad | Usar para |
|---|---|
| 1 (splash) | revelación, llegada, escala monumental, clímax, golpe irreversible — debe ganarse el espacio, no usar porque "se ve cool" |
| 2 | antes/después, pregunta/respuesta, calma/horror — pocas viñetas generan peso |
| 3 | preparación → cambio → consecuencia, buen ritmo cinematográfico |
| 4 | establecer / desarrollar / alterar / cerrar — versátil, buen default cuando la escena necesita claridad |
| 5-6 | conversación, persecución, investigación, escalada — evitar grilla uniforme automática |
| 7+ | montaje, simultaneidad, caos deliberado, compresión temporal — deben sentirse necesarias, nunca burocráticas |

**Gran panel dominante + inserts:** uno de los recursos centrales. El panel grande responde "¿qué ocurre?"; los inserts (ojos, manos, herida, objeto, reacción simultánea) responden "¿qué significa?". No usar inserts para repetir la misma acción desde otro ángulo.

## 3. Orientación de panel — vertical por defecto

Elseframe es cómic digital de scroll vertical. **El panel vertical es la orientación por defecto** en cualquier página de más de un panel — tiras apiladas, proporciones altas.

El panel horizontal es **excepción deliberada**, no alternativa equivalente. Usar solo para: horizonte, distancia, confrontación cara a cara, observación/pausa, acción lateral, respiración — y declarar el motivo. No hace falta justificar el vertical; sí el horizontal.

Tamaño del panel = percepción temporal: panel grande prolonga y pesa; panel chico acelera y fragmenta; splash puede congelar el tiempo.

## 4. Recursos visuales — tabla de decisión

**Regla crítica: estos recursos NO dependen del Render Mode.** Se usan con libertad dentro de Base Render — no están reservados para páginas "importantes". Para cada página, elegir y declarar en positivo al menos uno, en función del dueño emocional y la progresión emocional. "Ninguno, viñetas estándar" solo es válido para escenas deliberadamente neutras (setup funcional sin carga emocional), y debe ser decisión consciente, no omisión.

| Recurso | Usar para | No usar cuando |
|---|---|---|
| Close-up | aislar rostro/gesto para leer emoción | la emoción ya es legible en plano medio; banaliza si se repite en cada panel |
| Extreme close-up | detalle mínimo con carga simbólica (ojo, mano, objeto) | no hay carga emocional/narrativa específica en ese detalle |
| Reducción progresiva de plano | tensión creciente, foco emocional in crescendo | la escena no tiene escalada |
| Plano general | escala, aislamiento, contexto | se necesita intimidad |
| Fondo blanco | sacar la escena de contexto para impacto puro | la ubicación todavía importa para la lectura |
| Fondo negro | vacío, muerte, amenaza, silencio | se usa solo porque "se ve dark", sin función |
| Silueta | brutalidad sin depender de detalle anatómico, o identidad oculta un instante | la identidad debe ser clara en ese instante |
| Sombras / masas negras duras | dirigir la mirada, ocultar información sensible, tensión | se usa como textura decorativa |
| Espacio negativo | soledad, espera, vulnerabilidad | cada centímetro necesita información |
| Profundidad 2D (perspectiva, superposición, escala) | dar profundidad sin look 3D | nunca reemplazar por render 3D real — eso está prohibido siempre |
| Ruptura de borde | personaje/objeto irrumpe hacia el lector | se usa en cada página, pierde significado |
| Debris como dirección visual | destrucción con función compositiva (dirige mirada, indica fuerza) | detalle decorativo sin dirección |

## 5. Acción, poder y contenido sensible — reglas compactas

- **Poderes:** la habilidad revela personalidad (creativa, disciplinada, brutal, precisa, improvisada, arrogante, temerosa, desesperada). No es excusa para llenar el panel de partículas.
- **Efectos visuales:** todo efecto aporta dirección, intensidad, estado de poder, velocidad, peligro o cambio — nunca saturación automática (sparks, smoke, bloom, glow, lens flares, rim lights por defecto). Si todo tiene efectos, el lector no sabe qué mirar.
- **Violencia — regla general:** impacto narrativo por sobre detalle fisiológico.
- **Sobre humanos/humanoides:** con violencia severa, favorecer representación estilizada — silueta, contraluz, fondo blanco/negro, cropping, sangre como forma gráfica, ropa dañada, reacción de otro personaje, impacto fuera de cuadro, aftermath. La sangre funciona como signo de daño, no estudio anatómico.
- **Robots/mechas:** puede mostrarse destrucción estructural directa — placas, cables, engranajes, chispas, piezas seccionadas.
- **Criaturas no humanas:** toleran destrucción física más directa cuando la escena lo requiere, pero claridad narrativa > detalle gratuito.
- **Caso ambiguo** (¿humano, humanoide, artificial, criatura?): si la diferencia cambia la representación, preguntar; si no se puede, usar la solución más conservadora.

## 6. Worldbuilding y continuidad — reglas compactas

- Mostrar el mundo (arquitectura, ropa, vehículos, tecnología, ruinas, comportamiento civil) antes de explicarlo.
- Revelación progresiva de una locación nueva: identidad visual → función → contexto → historia.
- Page turn: cuando sea posible, guardar la gran revelación para después del cambio de página. No todo necesita cliffhanger — un cierre también puede ser una mirada, un objeto, un silencio.
- **Continuidad visual a revisar siempre:** vestuario, heridas, accesorios, armas, ubicación, hora, clima, iluminación, daños ambientales, posición relativa, estado de poderes, objetos importantes.
- **Continuidad emocional:** cansancio, temor, bronca, distancia, confianza, lesión, tensión corporal también persisten entre páginas. Alguien que acaba de quebrarse no debe aparecer posando como estatua promocional en la página siguiente, salvo que la escena explique el cambio.
- **Error frecuente — repetición de viñetas:** repetir el mismo momento desde otra cámara no es progresión. Cada panel debe aportar preparación, cambio, consecuencia, reacción o información nueva.

## 7. Tests rápidos de diagnóstico

- **Necesidad de panel:** si lo elimino, ¿pierdo información, emoción o ritmo? Si no, probablemente sobra.
- **Personaje:** ¿la página muestra cómo alguien vive el hecho, o solo documenta que ocurrió? Si solo documenta, falta reacción/decisión/conducta.
- **Visual:** eliminando todo diálogo, ¿se entiende qué ocurre, dónde mirar, quién domina, qué cambió? Si no, hay dependencia verbal excesiva.
- **Composición:** ¿cuál es la imagen que el lector debería recordar? Si no hay respuesta clara, falta jerarquía.

**Niveles de corrección** (no saltar directo al 4): 1) ajuste menor (pose/objeto/plano/detalle) → 2) reorganización (tamaño/orden/jerarquía de paneles) → 3) reescritura de beats (misma función, otras acciones) → 4) reconstrucción (la página está mal planteada conceptualmente).

# PARTE 2 — PROTOCOLOS DE CASO ESPECIAL

## 8. Identidad visual ≠ estilo artístico del sheet

Regla crítica. Un sheet o página de referencia adjunta define **qué aspecto tiene** el elemento (identidad, diseño, proporciones, colores, accesorios), nunca **cómo se dibuja** (render, iluminación, acabado). No asumir que la técnica visual de una referencia debe copiarse solo porque se adjuntó para identificar algo.

**Regla empírica:** las negaciones textuales ("no 3D", "no glossy") son insuficientes por sí solas cuando la referencia adjunta tiene un acabado incompatible — el modelo tiende a reproducir la técnica de la imagen por sobre la instrucción textual. Por eso, siempre que sea posible, adjuntar una **imagen positiva de estilo** junto a la de identidad, en vez de confiar solo en negaciones.

## 9. Protocolo de Referencia Dual — identidad + estilo

Cuando se necesite fijar identidad y forzar técnica al mismo tiempo, declarar dos grupos con rol distinto en el prompt:

- **Grupo A (identidad):** sheet o concept art. Usar solo para diseño, proporciones, colores, accesorios. No copiar su render, iluminación, fondo o acabado.
- **Grupo B (Style Anchor / Style Complement):** página de estilo publicada. Usar solo para técnica de tinta y cel shading — peso de línea, masas gráficas, bordes de sombra duros, highlights controlados. No aporta identidad de personaje ni composición narrativa; no autoriza copiar layout.

Adjuntar una página de estilo como ancla; una segunda solo si aporta un rasgo específico que la primera no cubre, y declarar ese rasgo. Los nombres de archivo de las páginas de estilo son específicos de cada sesión — lo que se reutiliza es el perfil de rasgos (ej. "perfil villano monumental: negros extensos, contraluz, para clímax oscuro en Emphasis Render"), no la ruta.

Bloque de texto: usar 76D (largo) o declarar explícitamente qué imagen es Reference 1 (identidad) y cuál Reference 2 (técnica), con instrucción de que Reference 1 no aporta render y Reference 2 no aporta contenido.

## 10. Protocolo de Regeneración de Sheets al House Style

Para migrar un sheet viejo (diseño correcto, render desactualizado) al House Style actual:

- **Sin cambios de diseño:** Reference 1 = sheet viejo (identidad, discard render). Reference 2 = página de estilo (técnica, discard contenido). Layout: 2 full body + 1 close-up facial. Usar bloque 77C.
- **Con cambios de diseño:** mismo esquema, más un bloque `MODIFICATIONS TO APPLY — HIGHEST PRIORITY` que liste cada cambio explícito y gane por sobre Reference 1. Todo lo no listado se asume igual al sheet viejo. Precedencia: 1) modificaciones → 2) identidad de Reference 1 → 3) técnica de Reference 2.
- **Reprocesar una imagen ya generada (no un sheet neutro):** mismo esquema, pero Reference 1 preserva además composición completa — paneles, poses, encuadre, staging. Si todavía existe el prompt de texto original, regenerar desde ese prompt corregido casi siempre da mejor resultado que reprocesar el archivo final, porque el prompt conserva información (dueño emocional, referencias usadas) que la imagen terminada no tiene.

## 11. Tipos de referencia — cómo interpretar cada adjunto

| Tipo | Aporta | No aporta |
|---|---|---|
| A — Sheets/concept art de canon | identidad, diseño, proporción, color, continuidad | estilo artístico final (salvo indicación explícita) |
| B — Páginas de cómic como referencia narrativa | arquitectura, ritmo, escala, cámara, espacio negativo | una página para calcar |
| C/E — Páginas de House Style | línea, tinta, cel shading, masas de sombra | identidad de personaje, layout |
| D — Fotos/referencias reales | anatomía, arquitectura, objeto, pose | deben reinterpretarse siempre como cómic 2D |

Si hay duda sobre el rol de una referencia y puede cambiar fuertemente el resultado, preguntar.

# PARTE 3 — PROTOCOLO DEL CHAT DE PROMPTS

## 12. Orden de trabajo — 13 pasos

1. **Inventario visual canónico:** todo lo que será visible y tiene sheet/diseño establecido (personajes con variante de traje/estado, criaturas, secundarios, locación exacta, planeta/región, vehículo/nave, props recurrentes). Si un elemento aparece aunque sea al fondo, va en el inventario si existe referencia canónica. No listar lo que solo se menciona en diálogo.
2. Contexto inmediato — qué pasó antes.
3. Función narrativa — una frase.
4. Dueño emocional — quién la vive.
5. Progresión emocional — estado inicial → final.
6. **Render Mode** — ver sección 13.
7. **Recurso visual dominante** — ver sección 4, declarar en positivo.
8. Arquitectura — cantidad de paneles, jerarquía, orientación de cada uno (vertical por defecto).
9. Beats — qué cambia panel por panel. Evitar repetir el mismo momento desde otra cámara.
10. Continuidad — qué no puede cambiar respecto de páginas/sheets anteriores.
11. Traducción de referencias al House Style — confirmar que sheets dan identidad, nunca técnica.
12. Información retenida — qué todavía no se muestra.
13. Restricciones — al final del prompt, nunca al principio.

## 13. Selección de Render Mode — obligatoria

**Base Render — Classic Cel Shading** (default de la serie): diálogo, cotidianeidad, humor, setup, transición, exposición, escenas íntimas sin pico dramático, acción funcional/táctica, peleas en fase regular, continuidad normal.

**Emphasis Render — Cinematic Hard-Edged Cel Shading**: splash/semisplash de alto peso, revelaciones mayores, primera aparición importante, transformación, clímax, golpe irreversible, muerte de gran peso, cierre de arco. Fórmula técnica: *hard-edged cel-shading as the structural base, with selective soft transitions only for atmospheric light, skin, glow, reflected color and bloom.* La estructura de sombra dura nunca se vuelve pintura blanda incluso acá.

**Pregunta de decisión:** ¿esta página debería sentirse visualmente más importante que una página normal? No → Base. Sí, claramente → Emphasis. Duda → Base. No usar Emphasis solo porque hay acción, poder, noche, fuego o "se ve premium" — la intensidad necesita contraste.

**Regla del beat dominante:** si la página tiene varios beats de distinto peso, el Render Mode responde al beat dominante, no a cada microacción. No cambiar de shading arbitrariamente entre paneles salvo que la transición sea parte explícita de la narrativa.

**Regla de escalada:** dentro de una secuencia larga puede progresar Base → Emphasis → Base (ej. inicio regular de pelea, transformación, aftermath silencioso). El cambio de acabado puede funcionar como señal subconsciente de que la historia cruzó un umbral.

## 14. Preguntas del chat de prompts

Preguntar solo si falta información capaz de cambiar significativamente el diseño: función narrativa, dueño emocional, estado inicial/final, acontecimiento obligatorio, revelación que debe ocultarse, personajes presentes, variante exacta de traje cuando existan varias, qué locación/vehículo corresponde, continuidad crítica, naturaleza humana/no humana de una víctima si importa, cuál sheet es canónico ante contradicción, referencia indispensable no adjuntada.

No preguntar lo que ya resuelven el canon, los sheets adjuntos o una inferencia visual menor. Máximo 3 preguntas críticas por ronda.

## 15. Formato obligatorio de salida

Todo prompt empieza con la **cabecera de referencias visibles en esa página**, antes de la función narrativa:

```text
Characters appearing on this page:
- [Character — exact visual/costume state]

Location appearing on this page:
- [Exact canonical location / sector / region]

Vehicles / ships / major recurring props appearing on this page:
- [Canonical element, or None]

Visual reference rule:
Use the provided sheets and concept art for all listed recurring elements as strict visual identity and continuity references. Preserve canonical design and recognizable features, but do not copy the rendering style or finish of the sheets. Redraw all referenced elements in the Elseframe House Style and in the selected Render Mode.

Render Mode:
- [Base Render — Classic Cel Shading / Emphasis Render — Cinematic Hard-Edged Cel Shading]

Dominant visual device:
- [Recurso elegido de la sección 4 + una frase de por qué corresponde a esta página]
```

Después: hora/condiciones (si importa) → función narrativa → dueño emocional → progresión → arquitectura (con orientación por panel) → prompt de página completa (lectura, composición general, relación entre paneles) → panel por panel (plano + orientación si no es vertical + recurso usado + acción + intención + elementos canónicos) → continuidad obligatoria → información retenida → restricciones.

## 16. Regla de balance — instrucción positiva antes que restricción

Acumular restricciones nuevas sin contrapeso positivo empuja al modelo hacia el resultado más seguro y promedio (grilla plana, sin recurso narrativo), sin importar cuántas veces se explicó *cuándo sí* usar cada recurso en otra parte de la guía.

- No dispersar restricciones nuevas fuera de la sección 20 y los bloques 76/77 — si aparece un patrón de falla, corregirlo ahí.
- En cada prompt, redactar primero el recurso visual elegido en positivo ("esta página usa un extreme close-up sobre la mano porque...") antes del bloque de restricciones al final.
- Ante la duda entre sumar una restricción más o reforzar una instrucción positiva existente, preferir reforzar la positiva.

# PARTE 4 — HOUSE STYLE (definición de render)

## 17. Definición general

Cómic americano 2D, dibujado y entintado a mano, con línea de tinta de grosor variable orgánico, anatomía estilizada y expresiva, siluetas claras. Cel shading clásico de 2-3 niveles tonales, bordes de sombra duros y gráficos. Coloración de cómic contenida, color local controlado. Nunca 3D, CGI, fotorrealismo, ni acabado pictórico/airbrush.

## 18. Reglas de render — compactas

- **Dibujo y entintado:** contorno exterior + línea interior + masa negra como jerarquía. Hachurado o textura selectiva permitida; nunca ruido procedural uniforme.
- **Cel shading:** color base + una sombra dura principal + ocasional segunda sombra profunda. 2-3 niveles tonales por superficie. Nunca gradiente continuo modelando toda la figura.
- **Sombras:** hacen trabajo narrativo real — volumen, dirección de luz, clima emocional (sección 4, "sombras y masas negras"). No decorativas.
- **Color:** de cómic, unificado por la atmósfera de la escena sin perder color local.
- **Nivel de detalle:** el foco decide el detalle. Sin poros, sin remaches infinitos, sin hipertextura de tela, sin detalle que compita con la silueta. Regla: si el detalle perjudica la lectura, reducir detalle.
- **Brillos y reflejos — acabado seco:** no agregar brillo para que algo parezca premium; el reflejo surge del material/entorno/Render Mode. Máximo **un** highlight amplio y deliberado por plano de material. **Prohibido:** puntos especulares dispersos, sparkle/starburst, sheen de "mojado". El objetivo es acabado seco de calidad de impresión, no brillo fotográfico — esto no reduce el dramatismo de la sombra, solo elimina el brillo cosmético.
- **Materiales:** tela y cuero predominantemente mate; metal = forma + una sombra dura + un highlight amplio máximo; vidrio/agua pueden tener reflejo claro cuando el material lo justifica.
- **Glow:** solo desde fuente emisiva real y explícitamente descrita. Bloom mínimo o ausente en Base Render; controlado alrededor de fuentes reales en Emphasis Render. Nunca bloom decorativo.
- **Iluminación:** motivada por la escena, no genérica de estudio.
- **Rostros:** cel shading preciso — color base + una sombra dura + highlight mínimo solo donde haga falta. Sin poros, sin sudor brillante salvo que la narrativa lo pida, sin puntos blancos.
- **Fondos:** se simplifican o densifican según función narrativa — foreground con detalle moderado, midground simplificado, background como siluetas/masas agrupadas en escenas de multitud o distancia.
- **Profundidad sin 3D:** se logra con perspectiva, superposición, escala relativa y masas de color — nunca con apariencia de render 3D/CGI.
- **Composición de acción:** diagonales, escorzo, pocos cortes para peso; fragmentación para velocidad o confusión (ver sección 4).
- **Texto y rotulación:** por defecto, en páginas narrativas, portadas, sheets y piezas de locación/vehículo, dejar zonas visualmente calmas para la rotulación posterior y nunca generar texto, letras, cartelería legible ni logos. Existen solo dos excepciones controladas: la **contraportada editorial** (bloque 76E + guía 03) y la **placa de establecimiento de locación** en una página narrativa que abre un cambio real de lugar (bloque 76F).

## 19. Restricciones duras — siempre, salvo excepción explícita en el prompt

No 3D render · no CGI look · no photorealism · no glossy overrendering · no scattered specular highlight dots/sparkle sobre una misma superficie (máx. un highlight amplio por plano) · no painterly airbrush finish · no bloom sin fuente emisiva real justificada por el Render Mode · no glow gratuito · no reflejos innecesarios · no ruido procedural uniforme ni microtextura fotográfica · no gradiente suave modelando toda la superficie de un personaje · no speech bubbles · no captions · no texto/letras/cartelería legible · no watermarks.

**Excepciones controladas para texto:**

1. **Contraportada editorial — bloque 76E:** puede generar dentro de la composición el copy final suministrado: título, encabezado, recap, créditos y folio si corresponden. Debe reproducirlo exactamente, sin inventar, completar, resumir, traducir ni corregir palabras.
2. **Placa de establecimiento de locación — bloque 76F:** una página narrativa puede generar exclusivamente el nombre canónico exacto de la nueva locación y, si el prompt lo declara, un único calificador geográfico breve. Solo aparece en el primer plano general después de un cambio real de lugar; no se repite en páginas consecutivas dentro de la misma locación.

Estas excepciones no habilitan speech bubbles, captions narrativos, cartelería ambiental, diálogos, logos no suministrados ni texto nuevo. Portadas, sheets y piezas de locación/vehículo no pueden autorizar texto generado.

Si el prompt pide otra excepción explícita (ej. un efecto de energía puntual), esa excepción vale solo para ese elemento — no relaja el resto de la lista.

## 20. Bloques House Style reutilizables

**76A — Base Render (largo):**
> 2D hand-drawn American comic-book artwork, entirely hand-inked, organic variable-width black ink contours, expressive stylized anatomy, clear readable silhouettes, controlled medium detail, hard graphic shadow shapes, two to three dominant tonal levels per surface, selective hatching or subtle print-like texture, restrained environmental color. Selective material-correct highlights, minimal bloom, glow only from genuinely emissive sources. Maximum one broad, deliberate highlight per material plane — no scattered specular highlight dots, no sparkle or starburst highlights, no wet-look sheen. Shadow does real narrative work through hard-edged shapes describing volume, light direction and mood; the finish should read as dry, matte comic-print ink and flat color, not photographic gloss. Strong narrative composition and depth through perspective, overlap and foreshortening. No photorealism, no CGI, no 3D render, no glossy overrendering, no uniform procedural noise, no photographic microtexture, no painterly airbrush modeling on figures, no speech bubbles, no captions, no text, no readable signage, no watermarks.

**76B — Emphasis Render (largo):**
> 2D hand-drawn American comic-book artwork, entirely hand-inked, organic variable-width black ink contours, expressive anatomy, clear silhouettes, bold black shadow masses, localized hatching or print-like texture. Hard-edged graphic shading remains the structural base. Use selective rim light, motivated reflected color, controlled bloom around genuinely bright sources, stronger atmospheric depth and deliberate color separation. Even with richer lighting, keep highlights to one broad, deliberate shape per material plane — no scattered specular highlight dots, no sparkle or starburst highlights, no wet-look sheen; the finish must still read as dry ink-and-flat-color, not photographic gloss. The result must remain graphic and ink-led, never painterly or 3D. No photorealism, no CGI, no glossy overrendering, no uniform noise filter, no photographic microtexture, no gratuitous glow, no speech bubbles, no captions, no text, no readable signage, no watermarks.

**77A — Base Render (corto):**
> 2D American comic-book artwork with a hand-drawn, hand-inked appearance; organic variable-width black linework, expressive stylized anatomy, clear silhouettes, controlled medium detail, hard graphic shadow shapes, two to three dominant tonal levels, selective hatching or subtle print-like texture, restrained environmental color and material-correct highlights. Maximum one broad highlight per material plane — no scattered specular dots, no sparkle, no wet-look sheen; dry matte comic-print finish. Soft transitions only in atmosphere, distance, energy or localized light. No 3D, CGI, photorealism, glossy overrendering, uniform noise, speech bubbles, text or watermarks.

**77B — Emphasis Render (corto):**
> 2D American comic-book artwork with a hand-drawn, hand-inked appearance; organic variable-width black linework, expressive anatomy, clear silhouettes, bold black masses and localized hatching or print-like texture. Hard-edged graphic shading remains the structural base; selective soft transitions may enrich atmosphere, skin, fog, smoke, energy, reflected color and bloom. Even with richer lighting, keep highlights to one broad shape per material plane — no scattered specular dots, no sparkle, no wet-look sheen. Cinematic but ink-led, with motivated rim light and controlled glow. No 3D, CGI, photorealism, glossy or painterly figure modeling, uniform noise, speech bubbles, text or watermarks.

**76C / 77C — Regeneración de Sheet (identidad + técnica, sin cambios de diseño):**
> Same structure as 76A/76B, plus: "TWO REFERENCE IMAGES ARE ATTACHED — Reference 1 (old sheet): identity only, discard rendering. Reference 2 (style page): technique only, discard content. Redraw fully in House Style, preserving only design identity."

**76D — Referencia Dual para Páginas (largo):**
> Same structure as 76A/76B, plus explicit declaration of which attached image is Style Anchor (technique) and which is the identity/canon reference (design) — Style Anchor never dictates content or layout, canon reference never dictates rendering.

**76E — Excepción Tipográfica de Contraportada (complemento obligatorio de 76A/76B):**
> BACK COVER TYPOGRAPHY EXCEPTION — This is the only Elseframe production piece allowed to generate extended editorial copy as part of the final image. ## 21. Errores frecuentes de generación

- **Página que parece concept art:** degradés suaves, luz atmosférica difusa, sombreado por gradiente continuo, casi sin línea de tinta visible. Corrección: forzar bloque 76/77 explícito + Reference 2 de técnica, no confiar solo en negaciones.
- **Todos los paneles "épicos":** usar Emphasis Render en cada panel sin contraste — pierde impacto por saturación. Corrección: aplicar regla de economía visual (sección 13) y regla de balance (sección 16).
- **Repetición de viñetas** (ver sección 6): revisar que cada panel aporte cambio, no solo otro ángulo del mismo instante.
- **Contaminación estética de sheet:** el resultado imita el render de un sheet de identidad. Corrección: aplicar Protocolo de Referencia Dual (sección 9), nunca depender solo de "no copiar el render" en texto.

# PARTE 5 — CIERRE

## 22. Cinco reglas visuales inviolables

1. Personaje antes que trama, también en imagen.
2. Toda página tiene dueño emocional y progresión visible.
3. Los recursos visuales (sección 4) son independientes del Render Mode — se usan también en Base Render.
4. El vertical es la orientación por defecto; el horizontal se justifica.
5. La identidad de un sheet nunca determina su técnica de render.

## 23. Checklist final antes de aprobar un prompt

- [ ] ¿Está la cabecera de referencias (sección 15) completa?
- [ ] ¿Se declaró el Render Mode explícitamente, con justificación si es Emphasis?
- [ ] ¿Se declaró un recurso visual dominante en positivo?
- [ ] ¿Los paneles son verticales salvo excepción justificada?
- [ ] ¿Las restricciones están al final del prompt, no dispersas ni al principio?
- [ ] ¿Los sheets adjuntos están marcados como identidad, no como técnica?
- [ ] ¿La continuidad respecto de páginas anteriores está resuelta?
- [ ] ¿Si es contraportada, incluye el copy final exacto y el bloque 76E? ¿Si abre una nueva locación, incluye el copy exacto y el bloque 76F? Fuera de esos casos, ¿prohíbe todo texto generado?

## 24. Objetivo final

No es la complejidad de la historia, ni cuántos recursos visuales caben en una página, ni cuán espectacular es el render. Es: entiendo qué está pasando, entiendo qué significa para esta persona, y quiero ver qué ocurre después.
